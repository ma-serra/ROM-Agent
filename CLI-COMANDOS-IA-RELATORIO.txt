│ 2. ROM PARECER (ALIAS DE ANALISAR COM FOCO EM RISCOS)                     │
└────────────────────────────────────────────────────────────────────────────┘

COMANDO:
  rom parecer <arquivo_ou_texto>

SUBAGENTE:
  analise-processual (com prompt focado em riscos)

FUNCIONALIDADE:
  Emite parecer jurídico conclusivo com foco em RISCOS, CHANCES DE ÊXITO
  e RECOMENDAÇÕES ESTRATÉGICAS.

DIFERENCIAL EM RELAÇÃO A "ANALISAR":
  - Enfatiza conclusões práticas
  - Avalia chances de êxito percentuais
  - Identifica riscos processuais críticos
  - Fornece recomendações estratégicas claras
  - Foco em tomada de decisão

PROMPT DO SUBAGENTE:
  "Analise o seguinte caso e emita um PARECER JURÍDICO conclusivo, com foco
   em RISCOS, CHANCES DE ÊXITO e RECOMENDAÇÕES ESTRATÉGICAS: [conteúdo]"

OUTPUT:
  Parecer estruturado com:
  - Relatório do caso
  - Análise de mérito
  - Riscos identificados (alto/médio/baixo)
  - Chances de êxito (%)
  - Recomendações estratégicas
  - Conclusão fundamentada

MÉTODO IMPLEMENTADO:

  Reutiliza mesmo método com flag especial

EXEMPLOS DE USO:

┌────────────────────────────────────────────────────────────────────────────┐
│ 3. ROM RESUMO (SISTEMA DE 3 CAMADAS)                                      │
└────────────────────────────────────────────────────────────────────────────┘

COMANDO:
  rom resumo <arquivo_ou_texto> --camada <1|2|3>
  rom resumo <arquivo_ou_texto> -l <1|2|3>

SUBAGENTE:
  resumo-executivo

FUNCIONALIDADE:
  Gera resumos executivos PERFEITOS e IRRETOCÁVEIS em 3 níveis de densidade.

SISTEMA DE 3 CAMADAS:

  CAMADA 1 - BÁSICO:
    - Síntese fática
    - Enquadramento jurídico
    - Pedidos e pretensões
    - Situação atual do processo

  CAMADA 2 - DENSO (PADRÃO):
    - Tudo da Camada 1 +
    - Jurisprudência aplicável
    - Súmulas e precedentes
    - Temas de repercussão geral
    - Recursos repetitivos
    - Estratégia processual sugerida

  CAMADA 3 - APRIMORADO:
    - Tudo das Camadas 1 e 2 +
    - PREQUESTIONAMENTO completo e técnico
    - LEADING CASES com análise detalhada
    - ADI, ADC, ADPF relacionados
    - Prescrição, decadência e preclusão
    - Matriz de riscos estruturada

FLAGS SUPORTADAS:
  --camada <1|2|3>  Define densidade do resumo
  -l <1|2|3>        Atalho para --camada

DEFAULT:
  Camada 2 (se não especificado)

PROMPT DO SUBAGENTE:
  "Gere um RESUMO EXECUTIVO em CAMADA [N] do seguinte processo: [conteúdo]"

OUTPUT:
  Resumo formatado conforme camada solicitada, com:
  - Cabeçalho indicando a camada
  - Todos os elementos da camada escolhida
  - Formatação markdown estruturada

MÉTODO IMPLEMENTADO:
  async gerarResumo(input, flags = {})
  Localização: src/cli-advanced.js, linha ~584

EXEMPLOS DE USO:
  rom resumo processo.pdf --camada 3
  rom resumo autos.txt -l 1
  rom resumo "Ação de cobrança" --camada 2

  REDATOR CÍVEL (padrão):

TIPOS DE PEÇAS SUPORTADAS:

    apelacao, agravo_instrumento, recurso_especial, recurso_extraordinario,

    reclamacao_trabalhista, contestacao_trabalhista, recurso_ordinario,
    agravo_peticao, recurso_revista

FLAGS SUPORTADAS:
  --tipo-peca <tipo>  Tipo da peça a redigir
  -p <tipo>           Atalho para --tipo-peca

PROMPT DO SUBAGENTE:
  "Redija uma [tipo_peca] com base no seguinte contexto: [contexto]"

OUTPUT:
  Peça jurídica completa formatada com:
  - Cabeçalho processual
  - Qualificação das partes
  - Fundamentação jurídica
  - Pedidos estruturados
  - Requerimentos finais
  - Formatação profissional

┌────────────────────────────────────────────────────────────────────────────┐
│ 5. ROM PESQUISAR (COM SISTEMA ANTI-ALUCINAÇÃO)                           │
└────────────────────────────────────────────────────────────────────────────┘

COMANDO:
  rom pesquisar <termo_jurisprudencial> [--tribunal <sigla>]

SUBAGENTE:
  jurisprudencia

FUNCIONALIDADE:
  Pesquisa jurisprudência com SISTEMA CRÍTICO DE SEGURANÇA ANTI-ALUCINAÇÃO
  que impede o agente de inventar ou parafrasear decisões judiciais.

★★★ REGRA CRÍTICA DE SEGURANÇA - ANTI-ALUCINAÇÃO ★★★

O prompt enviado ao subagente contém REGRAS ESTRITAS:

  1. PROIBIDO parafrasear ementas
  2. PROIBIDO resumir julgados
  3. PROIBIDO criar decisões fictícias
  4. OBRIGATÓRIO transcrever blocos LITERAIS encontrados na busca
  5. Se não encontrar resultado: retornar "❌ NENHUM RESULTADO LOCALIZADO"
  6. Se detectar discrepância: retornar "⚠️ BLOQUEIO DE SEGURANÇA"

PROMPT COM ANTI-ALUCINAÇÃO (trecho):
  "REGRA CRÍTICA DE SEGURANÇA - ANTI-ALUCINAÇÃO:
   Você está PROIBIDO de parafrasear, resumir ou criar ementas.
   Você DEVE transcrever LITERALMENTE os blocos de texto encontrados.
   Se não encontrar resultado concreto, retorne: '❌ NENHUM RESULTADO LOCALIZADO'
   Se detectar discrepância, BLOQUEIE com: '⚠️ BLOQUEIO DE SEGURANÇA'"

FONTES DE PESQUISA:
  - STF, STJ, TST, TSE, STM (Tribunais Superiores)
  - TRFs 1-6 (Tribunais Regionais Federais)
  - TJs de todos os estados
  - TRTs (Tribunais Regionais do Trabalho)
  - JusBrasil, Conjur (agregadores)

FLAGS SUPORTADAS:
  --tribunal <sigla>  Tribunal específico (STJ, STF, TJSP, etc.)

OUTPUT ESPERADO:
  Para cada julgado encontrado:
  - Tribunal/Órgão/Número (transcrição literal)
  - Relator e Data (transcrição literal)
  - Ementa COMPLETA (transcrição literal)
  - Tese fixada (se houver - transcrição literal)
  - Aplicabilidade ao termo pesquisado

MÉTODO IMPLEMENTADO:
  async pesquisarJurisprudencia(termo, flags = {})
  Localização: src/cli-advanced.js, linha ~701

EXEMPLOS DE USO:
  rom pesquisar "dano moral" --tribunal STJ
  rom pesquisar "prescrição tributária"
  rom pesquisar "adicional de periculosidade" --tribunal TST

VALIDAÇÃO:
  ✅ Sintaxe: PASSOU
  ✅ Teste funcional: PASSOU
  ✅ Sistema anti-alucinação implementado no prompt
  ✅ Regras de segurança documentadas

IMPORTÂNCIA CRÍTICA:
  Este comando é FUNDAMENTAL para evitar que o agente invente jurisprudência,

┌────────────────────────────────────────────────────────────────────────────┐
│ 6. ROM PROGNOSTICO (ANÁLISE COMBINADA DUPLA)                              │
└────────────────────────────────────────────────────────────────────────────┘

COMANDO:
  rom prognostico <caso>

SUBAGENTES (PIPELINE SEQUENCIAL):
  1. analise-processual (análise do caso)
  2. prazos             (análise temporal e riscos)

FUNCIONALIDADE:
  Gera prognóstico de êxito processual combinando análise de mérito com
  avaliação de riscos temporais (prescrição, decadência, preclusão).

PIPELINE DE EXECUÇÃO (2 FASES):

  FASE 1 - ANÁLISE DO CASO:
    Subagente: analise-processual
    Prompt: "Analise este caso para prognóstico de êxito: [conteúdo]"
    Output: Análise completa do mérito, fundamentos, provas

  FASE 2 - ANÁLISE TEMPORAL:
    Subagente: prazos
    Prompt: "Com base na análise, avalie PRESCRIÇÃO, DECADÊNCIA, PRECLUSÃO
             e RISCOS TEMPORAIS: [resultado_fase_1]"
    Output: Avaliação de prazos, causas suspensivas/interruptivas, riscos

OUTPUT COMBINADO:
  ═══ ANÁLISE DO CASO ═══
  [Resultado da Fase 1]

  ═══ PRAZOS E RISCOS ═══
  [Resultado da Fase 2]

ANÁLISE DE PRAZOS INCLUI:
  - Prescrição: prazos por matéria (CC, CDC, Trabalhista)
  - Causas suspensivas e interruptivas
  - Termo inicial e final
  - Decadência: legal e convencional
  - Preclusão: temporal, lógica, consumativa
  - Alertas de riscos temporais críticos

MÉTODO IMPLEMENTADO:
  async gerarPrognostico(caso)
  Localização: src/cli-advanced.js, linha ~776

EXEMPLOS DE USO:
  rom prognostico processo.pdf
  rom prognostico "Ação trabalhista de horas extras ajuizada em 2020"
  rom prognostico caso.txt
