# Metodologia ROM — síntese operacional

Três princípios: **fidedignidade** (fato = autos), **conferibilidade** (citação = fonte oficial ou marca ⚠️[NÃO VERIFICADO]), **anti-supressão** (não cortar documento do advogado sem autorização).

Pipeline: extração → diagnóstico de admissibilidade → redação → auditoria (subagentes).

Premissa: a maioria das derrotas em tribunal superior é de admissibilidade, não de mérito. As barreiras são finitas, publicadas e viram checagens explícitas. Nenhum modelo "lê a mente" do tribunal — o valor está no rigor verificável.

Nomenclatura de arquivos de prompt: `PROMPT_[AREA]_[tipo].txt`.
