# Roteamento de modelos e custos (Team)

Para desonerar sem perder qualidade, use o modelo mais barato que atende à tarefa:
- Operacional (triagem, formatação, inventário) → modelo rápido/barato (Haiku).
- Intermediário (leitura, extração, jurimetria) → Sonnet.
- Jurídico crítico (admissibilidade, redação final de recurso, auditoria) → Opus.

Trava de qualidade: nunca rebaixe as tarefas críticas para economizar — o custo de um erro jurídico supera a economia. Alavancas antes de cortar qualidade: cache de contexto repetido (−90%), batch para não urgente (−50%), e modelo aberto só no puramente mecânico. Não há API gratuita permanente da Anthropic.
