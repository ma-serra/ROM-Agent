# Checklist de admissibilidade — Recurso Especial (STJ)

Para CADA fundamento, responda PASSA / RISCO / NÃO PASSA e cite o trecho do acórdão.

1. **Via correta?** Matéria de lei federal infraconstitucional → REsp. (Constitucional → RE.)
2. **Prequestionamento** (Súmula 211/STJ; 282/356/STF): a questão foi decidida no acórdão? Onde? Se não → opor EDcl (art. 1.025).
3. **Súmula 7** (reexame de prova): a tese aceita os fatos fixados e discute consequência jurídica (PASSA) ou pede revisão de prova (NÃO PASSA)? Reenquadrar quando possível.
4. **Súmula 5** (cláusula contratual): depende de reinterpretar cláusula? Reenquadrar como questão de lei/qualificação.
5. **Súmula 83**: o acórdão já segue a jurisprudência atual do STJ? Há distinção/superação a explorar?
6. **Súmula 284/STF** (fundamentação): dispositivo indicado com precisão e violação demonstrada analiticamente?
7. **Dissídio (alínea c)**: cotejo analítico + similitude fática + paradigma de tribunal diverso + fonte oficial?
8. **Admissão na origem**: antecipei os argumentos que a presidência usaria para inadmitir? Se inadmitir → AREsp (art. 1.042), atacando cada fundamento (Súmula 182).

Resultado: VIÁVEL / VIÁVEL COM AJUSTE / CORRIGIR ANTES / ABANDONAR.
